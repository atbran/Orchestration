# Messages to paste into models

Use [BOOTSTRAP.txt](BOOTSTRAP.txt) for the first migration/setup task. It
points to the current host folder and authorizes only what the actual user
task authorizes; it is not a request to start a feature automatically.

After the pack is staged inside the AO project's reviewed base, use
[ORCHESTRATOR.txt](ORCHESTRATOR.txt) for the project coordinator,
[WORKER.txt](WORKER.txt) for implementation and [REVIEWER.txt](REVIEWER.txt)
for independent review. Fill bracketed values before sending.

Each prompt intentionally stays short. Assignments and complete approved
plans live in readable files. Do not paste the entire instruction pack into
a shell argument. No file in this directory is an automatic launcher.
